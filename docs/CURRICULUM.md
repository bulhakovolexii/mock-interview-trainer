# Junior Fullstack curriculum

Priority: JavaScript, Angular, Node.js/Express, then HTML/CSS. React is excluded.

JavaScript covers types, coercion, scope/hoisting, functions/closures/`this`, objects and arrays, copying, array methods, collections, prototypes/classes, promises/async and the event loop, DOM/events, storage, fetch/CORS, and modules. Coding emphasizes practical transformations, closures, timers, asynchronous work, and debugging. Output questions are short and avoid trivia.

Angular covers modern standalone components, templates/control flow, communication, lifecycle, dependency injection, RxJS and cleanup, forms, routing, HTTP, and junior-level change detection. Older NgModule, `*ngIf`/`*ngFor`, and constructor-injection patterns are discussed as existing-codebase context. Coding tasks are small components or services, not full applications.

Node.js covers runtime and V8, event loop/nonblocking I/O, packages/modules, process/environment, files/paths, events, buffers/streams, and HTTP. Express covers routing, middleware, validation, REST/status codes, error handling, authentication concepts, CORS, and small in-memory APIs.

HTML covers semantics, document structure, forms and labels, accessibility, tables, metadata, scripts, and DOM. CSS covers cascade/specificity, box model, display/position, Flexbox/Grid, responsive styles, selectors, stacking, transitions, variables, and practical debugging.

Interview modes: normal mixed, topic focus, review, 10-question quick, and 35-question full mock. The selector uses weighted sampling and recent-question avoidance; the interviewer adjusts based on actual answers.
