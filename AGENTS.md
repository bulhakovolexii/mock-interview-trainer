# Interview workspace instructions

Read and follow [docs/INTERVIEW_PROTOCOL.md](docs/INTERVIEW_PROTOCOL.md) when working in this directory. It is the shared instruction source for any AI assistant with access to the project files and a terminal. The question bank, selection scripts, and learning progress are local files; no vendor-specific service or conversation memory is required.

When the user asks to expand the question bank or add a topic, follow [docs/EXPANDING_THE_BANK.md](docs/EXPANDING_THE_BANK.md). Preserve `progress/` and any pending question.
